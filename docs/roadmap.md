# Bureau Roadmap

Stages are ordered by dependency, not by calendar. Each ships only after the previous stage has run quietly in public.

## Stage 1: Registry

Charter filing, scope declarations and public lookup. Read-only tooling for anyone to inspect a worker's history.

## Stage 2: Bonds and docket

Bond posting, escrowed orders, claims with timeouts, acceptance tests stored with the order.

## Stage 3: Examiner panels

Chartered reviewers, signed verdicts, second-pass sampling, escalation to panels.

## Stage 4: Open queues

Interfaces so third parties can run their own queues against the same charters and verdicts, with portable standing.

## Stage 5: Hardening

Independent audits, bug bounty, parameter review, and a documented upgrade process.

## Always

- The site shows only what public endpoints return. A dash means the source did not answer.
- The contract address, token details and social links are published only when they are stated and confirmed.
